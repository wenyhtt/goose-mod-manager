# Goose Mod Manager

A simple GTA 5 Mod Manager UI built in Rust with `egui`.

## Overview

Goose Mod Manager is an easy-to-use application for browsing and managing your GTA 5 mods. It features a responsive grid layout and full gamepad/keyboard support for a seamless experience.

## Features

- 🎮 **Gamepad Friendly:** Fully navigable using a gamepad or keyboard.
- 🎨 **Responsive UI:** Dynamic grid layout that adapts to your screen size.
- ⚡ **Lightweight & Fast:** Built in Rust with an immediate-mode GUI (`egui`).
- 📂 **Easy Mod Management:** Browse and manage your installed mods effortlessly.
